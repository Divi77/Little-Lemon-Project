<h1 align="center"> Little Lemon  </h1>

<p align="center">
The little lemon app is the capstone project for Meta's Front-End Developer Certificate on Coursera. <br/>
Developed by <strong>Divi Maisuirya</strong>.
</p>

<h2 id="technologies">🚀 Technologies</h2>

This project was developed with the following technologies:

- React JS
- Typescript
- Styled Components
- Yup
- Formik
- Jest
- React Testing Library
- Git and Github
- Figma


<h2 id="run">💻 Running locally</h2>

```bash
npm install
npm run dev
```

Run the tests with `npm test`.
